## 解決すること

服の詳細ページの「生地画像」は、実際の服とはほとんど関係のない、美しい布のアップであることが多いものです。ふつうの天竺にシルクのつやを描いたり、ブランドの技術名を存在しない構造として描いたり。

このスタイルの目的は「きれいな生地の絵」ではなく、**この商品を買う価値になる素材の良さを正確に描くこと**です。だから **Shop 006** は描く前にひとつ手順を加えます。**調べること**です。

## まず調べ、それから画像

1. 渡された生地名、組成、加工、売りの中から、なじみのない、または曖昧な用語を拾います。
2. ブランド、メーカー、繊維業界、規格の情報源で確かめ、それぞれを分類します。繊維、糸、織り、編み、ラミネート、表面処理、仕上げ加工、機能技術、あるいは単なる商標名か。
3. 「素材が何か」「加工で何が起こりうるか」「ブランドが何を主張しているか」を分けます。裏付けのない主張を科学として描くことはありません。
4. 調べた結果を出典付きでタスクフォルダの `facts.md` に書き、あなたが確認できるようにします。
5. それから要の価値の見せ方を選びます。織りはマクロ、柔らかさはドレープとサイド光、通気性は孔、撥水は自然な水滴、保温は本当の厚みの断面。

## 用意するもの

- **生地または服の写真**（必須）：色、柄、織り、質感のスケールは写真どおり。
- **生地の説明**（必須）：名称、組成、加工、構造、機能、セールスコピー。多いほど良いです。
- **あなたの資料**（任意）：メーカーのテクニカルシートや試験報告書はそのまま渡せます。外部検索に送ることはありません。

## 使い方

### ステップ 1：インストール（1回だけ）

```bash
git clone https://github.com/nevertoday/xxd-shop-006.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-006" ~/.claude/skills/xxd-shop-006
```

Codex を使う場合は、同じフォルダを `~/.codex/skills/xxd-shop-006` にリンクしてください。インストール後は AI アシスタントのセッションを再起動します。

### ステップ 2：やりたいことを普通の言葉で言う

```text
/xxd-shop-006 3レイヤーのラミネートシェルです：XX-Tex 3L、表地 40D ナイロン、DWR。生地画像を作って
/xxd-shop-006 カシミヤ100%、12ゲージ天竺。素材だけ、文字なしで
/xxd-shop-006 接触冷感ニット、テクニカルシート添付。3:4 の生地メリット画像を作って
```

覚えるフラグはありません。サイズや枚数など決めていないことは一度にまとめて質問され、次回は前回の設定を再利用できます。

### ステップ 3：そのあと何をするか

1. 商品画像と説明を読み、まだ決まっていないことだけを質問します。サイズは用途から、ピクセル数付きで提案します。
2. まず生地の用語を調べ、出典付きの結果を `facts.md` に書きます。
3. コピーがないときは、確認済みの結果だけからラベルを下書きし、確認のあとで生成します。
4. サイズごとに構図を新しく作り、別の画像から切り抜くことはありません。
5. 納品前に1枚ずつ確認します。商品は変わっていないか、文字のつづりは正しいか、渡していない数字はないか。通らないものは報告して作り直します。
6. PNG を `~/Desktop/xxd/xxd-shop-006/` の下の新しいタスクフォルダに保存し、パスを伝えます。

## よくある質問

**AI アシスタントがウェブ検索できない場合は？**

まずそう伝え、あなたの資料と写真から見て分かることだけを使います。確認できない用語は画像に載せません。

**ラベルなしにできますか？**

はい。文字なしと言えば、純粋な素材の画像になります。

**何が必要ですか？**

3つです。① Claude Code や Codex など、Skills に対応した AI アシスタント。② 画像を生成できるモデル。アシスタント内蔵の画像生成、または Codex に設定したモデルプロバイダーで Responses API 経由で画像を生成するもの（既定は GPT Image 2）。③ Pillow 入りの Python 3.11 以上（`pip install pillow`）。

**お金はかかりますか？商用利用できますか？**

Skill は無料でダウンロードできます。画像生成の費用はあなた自身のモデルアカウントに請求されます。本プロジェクトは PolyForm Noncommercial ライセンスです。個人の学習・研究・テストには使えますが、ショップ運営、受託制作などの商用利用には事前に作者の書面による許可が必要です。末尾の「ライセンス」を参照してください。

**画像の大きさは？**

比率か正確なピクセル数を指定できます。実際のサイズはモデルが返したとおりで、こっそり拡大することはなく、ファイル名に本当のピクセル数が書かれます。

**画像内の文字に誤字は出ますか？**

AI の画像では、ときどき文字を間違えたり、ブランド名の横に ® のような小さな記号を足したりします。納品前に1枚ずつ拡大して確認し、通らないものは作り直します。このページの作例はすべてその確認を通っています。

**価格や販売数をでっち上げませんか？**

しません。価格、仕様、産地、販売数、受賞、認証など事実に見えるものは、あなたが提供したものか、商品にはっきり読める文字からだけ取ります。それ以外は載せず、「¥XX」の仮置きもしません。

**たくさんの商品を一度に処理できますか？**

できます。商品画像のフォルダを渡してください。1枚の画像に商品1つ、サイズと文字は一度だけ質問され、ある商品の事実やコピーが別の商品に混ざることはありません。

## 原則

- **スタイルは忠実に：** この Skill の背後には成熟した商業デザインのプロンプトがあります（[原文プロンプト](references/original-prompt/zh-CN.md) · [英語の参考訳](references/original-prompt/en.md)）。Skill はそれを書き換えたり、独自の色やアートディレクションを足したりせず、あなたの商品、サイズ、文字、事実をモデルに渡すだけです。
- **商品をデザインし直さない：** 商品画像があれば、形、色、パッケージの文字、ロゴは写真どおりです。
- **あなたの事実だけ、** そして商品はそれぞれ独立。ほかの商品、以前の結果、作例から何も借りません。
- **本物の PNG ビットマップ。** SVG やコードで描いた絵を画像として出すことはなく、実行のたびに新しいタスクフォルダを作ります。
- 画像上のラベルはすべて `facts.md` かあなたの資料にさかのぼれます。
