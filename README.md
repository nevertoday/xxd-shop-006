## 它解决什么

服装详情页上的“面料图”常常是一张漂亮的布料特写，却和这件衣服的布没什么关系：普通针织被画成了真丝光泽，品牌起的技术名被画成了不存在的结构。

原稿说得很直接：目标不是“做一张漂亮的布料图”，而是**把这个具体产品真正值得购买的材质价值准确表现出来**。所以 **Shop 006** 在作图之前多了一步：**先查清楚**。

## 先查证，再作图

1. 从你给的面料名称、成分、工艺和卖点里，挑出不熟悉或含义不明的词。
2. 优先查品牌官方、材料厂商、纺织行业和标准资料，弄清它到底是纤维、纱线、织法、针织组织、复合结构、表面处理、后整理、功能技术，还是只是一个商业名字。
3. 区分“材料本身的性质”“工艺可能带来的效果”和“品牌宣传的卖点”。没有证据的宣传，不会被画成科学事实。
4. 结果写进任务目录的 `facts.md`，每条都带来源，你可以逐条核对。
5. 再按核心价值选表现方式：织纹靠微距，柔软靠折叠和侧光，透气靠孔隙，防泼水靠可信的液滴，保暖复合靠真实层厚的剖面。

## 你需要准备

- **面料或服装图：** 必需。颜色、花纹、织法和纹理尺度都照着图来。
- **面料说明：** 名称、成分、工艺、结构、功能和卖点文字，越完整越好。
- **你自己的资料：** 厂商技术单、检测报告可以直接给，不会被送去外部检索。

## 快速判断

| 你关心的问题 | 回答 |
|---|---|
| **你会得到什么** | 一张准确、聚焦、大面积展示核心材质的面料图，需要时带极简专业标注 |
| **一眼可辨的特点** | 真实纤维与针脚 · 侧向光刻画起伏 · 干净背景 · 少量细线指示 |
| **它不会做什么** | 不把普通布画成高级材料、不把宣传话术画成功能演示、不让文字盖住纹理 |

## 开始使用

```bash
git clone https://github.com/nevertoday/xxd-shop-006.git
ln -s "$(pwd)/xxd-shop-006" ~/.claude/skills/xxd-shop-006
```

```text
# 带品牌技术名的冲锋衣面料：先查证，再出图
/xxd-shop-006 ./冲锋衣面料.jpg --product "三层压胶冲锋衣，面料：XX-Tex 3L，表层 40D 尼龙，DWR 防泼水" --size 3:4 --text prompt --locale zh-CN

# 羊绒针织，只要材质，不要字
/xxd-shop-006 ./羊绒衫细节.jpg --product "100% 山羊绒，12 针粗针平针" --size 1:1 --text none

# 已有厂商技术单
/xxd-shop-006 ./面料.jpg --product "凉感针织" --facts "厂商技术单：接触凉感 Qmax 0.21 W/cm²（GB/T 35263）" --size 3:4 --text prompt --locale zh-CN
```

常用参数：`--product` 面料说明 · `--facts` 你已有的数据 · `--size` · `--text prompt / exact / plan / none` · `--locale`。完整参数见[家族运行合同](references/shop-runtime.md)。

## 边界与信任

- 原始提示词逐字保存，是唯一的审美权威。
- 画面上的每一条标注都能在 `facts.md` 或你的资料里找到出处。
- 宿主没有检索工具时会告诉你，只用你提供的和图上看得见的信息，未证实的词不上画面。
