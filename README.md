**先查清这块布到底是什么，再做一张让人隔着屏幕“摸到”它的面料图。**
不把普通针织画成真丝，也不把品牌起的技术名画成不存在的结构。

| 一眼看懂 | |
|---|---|
| **交给它** | 面料或服装照片（必需）＋面料说明（名称、成分、工艺、卖点）；有技术单更好 |
| **你拿到** | 服装详情页的面料图：大面积展示核心材质，需要时带极简专业标注 |
| **风格特点** | 真实纤维与针脚 · 侧向光刻画起伏 · 干净背景 · 少量细线指示 |
| **最适合** | 服装、户外、家纺、箱包等需要讲清面料价值的详情页 |

> /xxd-shop-006 这是三层压胶冲锋衣的面料，XX-Tex 3L，表层 40D 尼龙，DWR 防泼水，做一张面料图

## 它解决什么

服装详情页上的“面料图”常常是一张漂亮的布料特写，却和这件衣服的布没什么关系：普通针织被画成真丝光泽，品牌起的技术名被画成不存在的结构。

这套风格的目标不是“做一张漂亮的布料图”，而是**把这件商品真正值得买的材质价值准确表现出来**。所以 **Shop 006** 在作图之前多了一步：**先查清楚**。

## 先查证，再作图

1. 从你给的面料名称、成分、工艺和卖点里，挑出不熟悉或含义不明的词。
2. 优先查品牌官方、材料厂商、纺织行业和标准资料，弄清它到底是纤维、纱线、织法、针织组织、复合结构、表面处理、后整理、功能技术，还是只是一个商业名字。
3. 区分“材料本身的性质”“工艺可能带来的效果”和“品牌宣传的卖点”。没有证据的宣传，不会被画成科学事实。
4. 结果写进任务文件夹的 `facts.md`，每条都带来源，你可以逐条核对。
5. 再按核心价值选表现方式：织纹靠微距，柔软靠折叠和侧光，透气靠孔隙，防泼水靠可信的液滴，保暖复合靠真实层厚的剖面。

## 你需要准备

- **面料或服装照片**（必需）：颜色、花纹、织法和纹理尺度都照着图来。
- **面料说明**（必需）：名称、成分、工艺、结构、功能和卖点文字，越完整越好。
- **你自己的资料**（可选）：厂商技术单、检测报告可以直接给，不会被送去外部检索。

## 怎么用

### 第一步：安装（只需一次）

```bash
git clone https://github.com/nevertoday/xxd-shop-006.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-006" ~/.claude/skills/xxd-shop-006
```

Codex 用户把同一个文件夹链接到 `~/.codex/skills/xxd-shop-006`。装好后重开一次 AI 助手的会话。

### 第二步：用大白话说出你要什么

```text
/xxd-shop-006 这是三层压胶冲锋衣的面料，XX-Tex 3L，表层 40D 尼龙，DWR 防泼水，做一张面料图
/xxd-shop-006 100% 山羊绒，12 针粗针平针，只要材质，不要字
/xxd-shop-006 凉感针织，附上厂商技术单，做一张 3:4 的面料卖点图
```

不用记参数。没说清的事（比如尺寸、张数），它会一次问齐；第二次用时可以直接沿用上次的设置。

### 第三步：它会这样做

1. 看你的商品图和描述，只问还没定的事；尺寸会按用途推荐比例，并告诉你像素。
2. 先查清面料术语，结论和来源写进 `facts.md`。
3. 没给文案时，只用查证过的条目起草标注，给你确认后再出图。
4. 每个尺寸都重新构图，不是从一张图裁出来的。
5. 交付前逐张检查：商品有没有被改、字有没有写错、有没有多出你没给的数字。不通过的会告诉你并重做。
6. PNG 存进 `~/Desktop/xxd/xxd-shop-006/` 下新建的任务文件夹，把路径告诉你。

## 常见问题

**我的 AI 助手不能上网怎么办？**

它会先告诉你，然后只用你提供的资料和图上看得见的信息；没证实的词不上画面。

**可以不要标注吗？**

可以，说“不要文字”就是一张纯材质图。

**需要什么才能用？**

三样东西：① 一个支持 Skills 的 AI 助手，比如 Claude Code 或 Codex；② 一个能出图的模型，可以是助手自带的出图能力，也可以是在 Codex 里配置好的、通过 Responses 接口出图的模型供应商（默认用 GPT Image 2）；③ 电脑上装有 Python 3.11 以上和 Pillow（`pip install pillow`）。

**要花钱吗？能商用吗？**

Skill 本身免费下载，出图费用由你自己的模型账户承担。本项目采用 PolyForm 非商业许可：个人学习、研究、测试可以直接用；用于店铺经营、接单交付等商业用途，需要先取得作者的书面授权，见文末“许可证”。

**出来的图有多大？**

你可以指定比例或准确像素。实际像素以模型返回为准，不会偷偷放大冒充高清，文件名里写的就是真实像素。

**图里的字会写错吗？**

AI 出图偶尔会写错字，或在品牌名旁多出 ® 这类小符号。交付前会逐张放大检查，发现问题就重做那一张；本页的样张都过了这一步。

**会不会乱写价格、销量？**

不会。画面上像事实的内容（价格、规格、产地、销量、获奖、认证……）只来自你提供的信息或商品图上看得清的字；没给就不写，也不放“¥XX”这种占位。

**能一次处理很多商品吗？**

能。把商品图文件夹交给它，每张图当作一件商品，尺寸和文字设置只问一次；每件商品的信息和文案互不串用。

## 它的原则

- **风格不走样：** 这款背后是一份成熟的商业设计提示词（[设计原文](references/original-prompt/zh-CN.md) · [English](references/original-prompt/en.md)）。Skill 不改写它，也不另加配色和美术指导，只把你的商品、尺寸、文字和事实交给模型。
- **商品不改款：** 有商品图时，造型、颜色、包装文字和 Logo 以图为准。
- **只用你给的事实，** 每件商品各管各的，不借用别的商品、旧成品或样张里的内容。
- **交付真实的 PNG 位图，** 不用 SVG 或代码绘图冒充；每次调用都新建任务文件夹。
- 画面上的每一条标注都能在 `facts.md` 或你的资料里找到出处。
