**First find out what this fabric really is, then make an image that lets shoppers feel it through the screen.**
No plain knit painted as silk, no brand's tech name drawn as a structure that does not exist.

| At a glance | |
|---|---|
| **You give** | A fabric or garment photo (required) plus the fabric description (name, composition, finish, selling points); a tech sheet is even better |
| **You get** | Detail-page fabric images that show the key material large, with minimal professional labels when useful |
| **The look** | Real fibres and stitches · raking light for relief · clean background · a few fine pointer lines |
| **Best for** | Apparel, outdoor gear, home textiles and bags whose detail pages need to explain the fabric |

> **Once installed, just say:**
>
> /xxd-shop-006 This is a 3-layer laminated shell: XX-Tex 3L, 40D nylon face, DWR — make a fabric image

## What it solves

The "fabric image" on an apparel page is often a beautiful cloth close-up with little to do with the actual garment: plain knit painted with silk sheen, a brand's tech name drawn as a structure that does not exist.

The aim of this style is not "a pretty fabric picture" but **an accurate picture of the material value that makes this product worth buying**. So **Shop 006** adds a step before drawing: **research**.

## Research first, then the image

1. Pick out unfamiliar or ambiguous terms from the fabric name, composition, finish and selling points you give.
2. Check brand, manufacturer, textile-industry and standards sources to classify each one: fibre, yarn, weave, knit, laminate, surface treatment, finishing, functional technology — or just a trade name.
3. Separate "what the material is", "what a process may do" and "what the brand claims". Unsupported claims are never drawn as science.
4. Write the findings, each with a source, to `facts.md` in the task folder so you can check them.
5. Then pick how to show the key value: macro for weave, folds and side light for softness, pores for breathability, believable droplets for water repellence, a true-thickness section for insulation.

## What to prepare

- **A fabric or garment photo** (required): colour, pattern, weave and texture scale follow it.
- **The fabric description** (required): name, composition, finish, structure, function and selling copy — the fuller the better.
- **Your own documents** (optional): manufacturer tech sheets and test reports can be given directly and are never sent to external search.

## How to use it

### Step 1: install (once)

```bash
git clone https://github.com/nevertoday/xxd-shop-006.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-006" ~/.claude/skills/xxd-shop-006
```

Codex users link the same folder into `~/.codex/skills/xxd-shop-006`. Restart your AI assistant's session after installing.

### Step 2: say what you want in plain words

```text
/xxd-shop-006 This is a 3-layer laminated shell: XX-Tex 3L, 40D nylon face, DWR — make a fabric image
/xxd-shop-006 100% cashmere, 12-gauge jersey — material only, no text
/xxd-shop-006 Cooling knit, tech sheet attached — make a 3:4 fabric benefit image
```

No flags to memorise. Anything you leave open, such as sizes or how many, is asked in one go, and next time you can reuse your previous settings.

### Step 3: what it does next

1. Reads your product photo and description and asks only what is still open; sizes are recommended from the use, with pixel dimensions.
2. It first researches the fabric terms and writes findings with sources to `facts.md`.
3. Without your copy, it drafts labels from the verified findings only, and generates after you confirm.
4. Every size is composed afresh, never cropped from another image.
5. Checks each image before delivery: is the product unchanged, is the text spelled right, are there numbers you never gave? Anything that fails is reported and redone.
6. Saves PNGs to a new task folder under `~/Desktop/xxd/xxd-shop-006/` and gives you the path.

## FAQ

**What if my AI assistant cannot search the web?**

It tells you first, then uses only your documents and what is visible in the photo; unverified terms stay off the image.

**Can I have no labels?**

Yes — ask for no text and you get a pure material image.

**What do I need?**

Three things: ① an AI assistant that supports Skills, such as Claude Code or Codex; ② an image-capable model — your assistant's built-in image generation, or a model provider configured in Codex that generates images through the Responses API (GPT Image 2 by default); ③ Python 3.11+ with Pillow (`pip install pillow`).

**Does it cost anything? Can I use it commercially?**

The Skill is free to download; image generation is billed to your own model account. The project uses the PolyForm Noncommercial licence: personal learning, research and testing are fine; running a shop, client work or other commercial use needs the author's written permission first — see "License" at the end.

**How large are the images?**

You can ask for a ratio or exact pixels. The real size is whatever the model returns — never secretly upscaled — and the file name states the true pixels.

**Will the text in the image have typos?**

AI images occasionally misspell words or add small marks such as ® next to a brand name. Every image is zoomed and checked before delivery, and any failure is redone; all samples on this page passed that check.

**Will it invent prices or sales numbers?**

No. Anything that looks like a fact — price, specs, origin, sales, awards, certifications — comes only from what you provide or text clearly readable on the product; otherwise it is left out, with no "¥XX" placeholder.

**Can it handle many products at once?**

Yes. Give it a folder of product photos: each image is one product, sizes and text are asked once, and no product's facts or copy leak into another's.

## Principles

- **The style stays true:** behind this Skill is a mature commercial design prompt ([original brief](references/original-prompt/zh-CN.md) · [English reading translation](references/original-prompt/en.md)). The Skill never rewrites it or adds its own colours or art direction; it only hands the model your product, sizes, text and facts.
- **The product is not redesigned:** with a product photo, shape, colour, packaging text and logo follow the photo.
- **Only your facts,** and each product stands alone — nothing borrowed from other products, earlier results or samples.
- **Real PNG bitmaps,** never SVG or code drawings passed off as images; every run creates a new task folder.
- Every label on the image traces to `facts.md` or your own documents.
