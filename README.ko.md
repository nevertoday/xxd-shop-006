## 해결하는 문제

의류 상세페이지의 "원단 이미지"는 실제 옷과 거의 상관없는 예쁜 천 클로즈업인 경우가 많습니다. 평범한 저지에 실크 광택을 그리고, 브랜드의 기술명을 존재하지 않는 구조로 그립니다.

이 스타일의 목표는 "예쁜 원단 그림"이 아니라 **이 상품을 살 가치가 되는 소재의 장점을 정확히 그리는 것**입니다. 그래서 **Shop 006**은 그리기 전에 한 단계를 더합니다. **조사**입니다.

## 먼저 조사하고, 그다음 이미지

1. 준 원단 이름, 조성, 가공, 셀링 포인트에서 낯설거나 모호한 용어를 골라냅니다.
2. 브랜드, 제조사, 섬유 업계, 표준 자료로 확인해 각 용어를 분류합니다. 섬유, 실, 직조, 편직, 라미네이트, 표면 처리, 후가공, 기능 기술, 아니면 그냥 상표명인지.
3. "소재가 무엇인지", "가공으로 무엇이 일어날 수 있는지", "브랜드가 무엇을 주장하는지"를 나눕니다. 근거 없는 주장을 과학처럼 그리지 않습니다.
4. 조사 결과를 출처와 함께 작업 폴더의 `facts.md`에 써서 확인할 수 있게 합니다.
5. 그다음 핵심 가치를 보여 줄 방법을 고릅니다. 짜임은 매크로, 부드러움은 주름과 측광, 통기성은 기공, 발수는 그럴듯한 물방울, 보온은 실제 두께의 단면.

## 준비할 것

- **원단 또는 옷 사진**(필수): 색, 무늬, 짜임, 질감의 스케일은 사진대로.
- **원단 설명**(필수): 이름, 조성, 가공, 구조, 기능, 판매 문구. 많을수록 좋습니다.
- **내 자료**(선택): 제조사 기술 자료와 시험 성적서를 그대로 줄 수 있고, 외부 검색으로 보내지 않습니다.

## 사용 방법

### 1단계: 설치 (한 번만)

```bash
git clone https://github.com/nevertoday/xxd-shop-006.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-006" ~/.claude/skills/xxd-shop-006
```

Codex 사용자는 같은 폴더를 `~/.codex/skills/xxd-shop-006`에 링크하세요. 설치 후에는 AI 어시스턴트 세션을 다시 시작합니다.

### 2단계: 원하는 것을 평소 말로 말하기

```text
/xxd-shop-006 3레이어 라미네이트 셸이에요: XX-Tex 3L, 겉감 40D 나일론, DWR. 원단 이미지를 만들어 줘
/xxd-shop-006 캐시미어 100%, 12게이지 저지. 소재만, 글자 없이
/xxd-shop-006 냉감 니트, 기술 자료 첨부. 3:4 원단 장점 이미지를 만들어 줘
```

외울 플래그는 없습니다. 사이즈나 장수처럼 정하지 않은 것은 한 번에 모아서 묻고, 다음에는 지난 설정을 다시 쓸 수 있습니다.

### 3단계: 그다음에 하는 일

1. 상품 이미지와 설명을 읽고 아직 정해지지 않은 것만 묻습니다. 사이즈는 용도에 맞춰 픽셀 크기와 함께 추천합니다.
2. 먼저 원단 용어를 조사하고 출처가 달린 결과를 `facts.md`에 씁니다.
3. 문구가 없으면 확인된 결과만으로 라벨 초안을 쓰고, 확인한 뒤에 생성합니다.
4. 사이즈마다 새로 구도를 잡고, 다른 이미지에서 잘라내지 않습니다.
5. 납품 전에 한 장씩 확인합니다. 상품이 바뀌지 않았는지, 철자가 맞는지, 주지 않은 숫자가 있는지. 통과하지 못한 것은 알리고 다시 만듭니다.
6. PNG를 `~/Desktop/xxd/xxd-shop-006/` 아래 새 작업 폴더에 저장하고 경로를 알려 줍니다.

## 자주 묻는 질문

**AI 어시스턴트가 웹 검색을 못 하면요?**

먼저 그렇게 알리고, 내 자료와 사진에서 보이는 것만 씁니다. 확인되지 않은 용어는 이미지에 넣지 않습니다.

**라벨 없이 할 수 있나요?**

네. 글자 없이라고 하면 순수한 소재 이미지가 나옵니다.

**무엇이 필요한가요?**

세 가지입니다. ① Claude Code나 Codex처럼 Skills를 지원하는 AI 어시스턴트. ② 이미지를 생성할 수 있는 모델: 어시스턴트에 내장된 이미지 생성, 또는 Codex에 설정한 모델 제공자로 Responses API를 통해 이미지를 생성하는 것(기본 GPT Image 2). ③ Pillow가 설치된 Python 3.11 이상(`pip install pillow`).

**비용이 드나요? 상업적으로 써도 되나요?**

Skill은 무료로 내려받을 수 있고, 이미지 생성 비용은 본인의 모델 계정에 청구됩니다. 자기 상품·스토어·브랜드(직원으로서 다니는 회사 포함)의 이미지를 만드는 것은 신청 없이 상업적으로 써도 됩니다. Skill 재판매, 유료 서비스화, 다른 사람을 위한 유료 이미지 제작은 먼저 작성자의 서면 허가가 필요합니다. 맨 아래 "라이선스"를 참고하세요.

**이미지는 얼마나 큰가요?**

비율이나 정확한 픽셀을 요청할 수 있습니다. 실제 크기는 모델이 돌려준 그대로이며 몰래 업스케일하지 않고, 파일 이름에 실제 픽셀이 적힙니다.

**이미지 속 글자에 오타가 생기나요?**

AI 이미지는 가끔 철자를 틀리거나 브랜드 이름 옆에 ® 같은 작은 기호를 덧붙입니다. 납품 전에 한 장씩 확대해 확인하고, 통과하지 못하면 다시 만듭니다. 이 페이지의 예시는 모두 그 확인을 통과했습니다.

**가격이나 판매량을 지어내나요?**

아니요. 가격, 사양, 원산지, 판매량, 수상, 인증처럼 사실로 보이는 것은 내가 준 것이나 상품에서 또렷이 읽히는 글자에서만 가져옵니다. 그 밖에는 넣지 않으며 "¥XX" 자리표시도 없습니다.

**상품 여러 개를 한 번에 처리할 수 있나요?**

네. 상품 이미지 폴더를 주세요. 이미지 하나에 상품 하나, 사이즈와 글자는 한 번만 묻고, 한 상품의 사실이나 문구가 다른 상품으로 새지 않습니다.
